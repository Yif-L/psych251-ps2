# psych251-ps2
[View the study guide](https://yif-l.github.io/psych251-ps2/)

A concise guide to p-values, multiplicity, p-hacking, statistical power, estimates and confidence intervals, and Bayes factors. Includes interactive charts, tables, and practice questions.

Based on Experimentology Chapters [5](https://experimentology.io/005-estimation.html), [6](https://experimentology.io/006-inference.html), and [10](https://experimentology.io/010-sampling.html), plus the three Week 3 lecture decks.

Created with assistance from OpenAI Codex.
